# C5 deterministic coverage

`full_single_gpu/result.json` records the one-GPU 50.91M-model coverage run on
`tinystories_debug`. It covered all 4,222 complete windows, padded two repeats
to finish the last 32-window update, and separately recorded 413 trailing
training tokens. Initial and final loss cover every validation target token,
including the 510-token final segment.

`resume_check.json` is generated by:

```bash
uv run python scripts/check_coverage_resume.py --device=cuda
```

It verifies exact equality of model hash, loss history and window progress for
a split 2+2 update run versus four uninterrupted updates. Checkpoint payloads
are intentionally ignored by Git; the compact result JSON preserves the
verification evidence.
